# Tinox IDE user manual

Tinox IDE is a Linux development environment built with KDE Frameworks and
KTextEditor. This development preview supports project editing, Tinox language
assistance, builds, running programs and a test explorer. Full debugger integration
and the accessibility review are still separate work items.

Read these pages in order for a first session:

| Page | What you will do |
|---|---|
| [Install and start](install.md) | Choose a package, prepare the toolchain and launch the IDE |
| [Your first project](first-project.md) | Create a small Tinox application and a test |
| [Edit and navigate](editor.md) | Open files, save, search, navigate and rename symbols |
| [Build, run and test](build-run-test.md) | Check and run code, select tests and read failures |
| [Preferences and troubleshooting](settings.md) | Configure tools, appearance and save behaviour |

Menu names below use the English UI and default shortcuts. Configured KDE shortcuts
can differ. The command palette (`Ctrl+Shift+P`) also finds available commands.

For contributing to this IDE, continue with [dogfooding](../dogfooding.md).
For implementation details, use the [architecture map](../architecture.md).
